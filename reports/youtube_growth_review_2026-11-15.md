# YouTube 成長観点レビュー (2026-11-15, Muse)

対象: 「アニメ日本史ラボ」Season 1 全10話 + 制作パイプライン。
根拠: プロジェクト実測 (script.json 全190シーン、QC、QAレポート)、
競合調査 (実在動画 約170本 / 26チャンネル、出典は調査レポート参照)、
対話演出・維持率の実務知見 (20項目チェックリスト)。
調査レポート: Muse 側 workspace/research_notes/yt-history-edu-competitors,
同 yt-dialogue-video-craft。

## この動画の型 (理解の確認)
受験生向けに、先生と生徒の対話で日本史を通史解説する 1本約9分のアニメ。
差別化は「受験ポイント明示+クイズ」。ベンチマークはアニメ神話劇場。

## 競合の実データから分かったこと (要点)
1. 再生数は通常回ではなく総集編・全体像で決まる (にっぽんぽん通常回
   2.5千〜2.2万回 vs 総集編 232万回。YouTube高校も長尺総集編が柱)。
2. 同一チャンネル内の格差は最大約900倍。テーマ選定が上限を決める。
3. VOICEVOX対話で伸びているのは「歴史×謎・末路・ミステリー」の
   フック概念との組み合わせ。純粋な教科書解説型の同規模事例なし。
4. タイトルは疑問形か「最上級+数字」が必須級 (最大ヒット例 90万回)。
5. 前編/後編に割ると後編は約半分になる。
6. Shorts はロング通常回の約16倍の発見力 (にっぽんぽん実測)。
7. 受験層の中核需要は「因果の流れ」と「重要度の可視化」(板書・色分け)。
8. 大手は固定曜日・固定時刻+話数番号が共通インフラ。

## 本プロジェクトの問題点

### P1 (再生数に直結)
- **[修正済] 向き合い**: 2人が同じ方向を向いていた。配置実測
  (先生=右190回/マナブ=左170回) に基づき先生素材を反転し全話再生成。
  スタイルガイドに原則を明文化。
- **冒頭フックなし**: OP 25秒 (ロゴ+タイトル) は離脱集中区間そのもの。
  競合の型は「挨拶ゼロで即本題」「結論先出し」か「問いかけ+驚き」。
  → 冒頭3秒で生徒の疑問 (例:「なぜ卑弥呼は中国に使いを送ったの?」)
  を置き、タイトル表示は3秒以内に短縮する構成へ変更すべき。
- **タイトル型**: 現行は説明型で疑問形・数字がない
  (例「日本の歴史、ここから始まる!〜縄文・弥生・古墳〜」)。
  競合の勝ち型は「なぜ〜?」「最大の謎」等のフック語+検索語の併記。
- **総集編の設計がない**: 全10話は通常回のみ。競合の再生構造では
  「全時代まるごと総集編 (1時間超)」が最大の入口。Season 完成時に
  総集編を1本組むことを最初から計画に入れるべき。
- **キャラが喋らない絵**: 表情差分・口パク・瞬き・聞き手リアクションが
  なく、静止画2枚の会話になっている。実務では最低装備とされる。
  先生=解説/マナブ=疑問の役割固定は良いので、マナブの驚き顔・
  先生のツッコミ顔など表情2〜3種と、聞き手側の頷きモーションを追加。

### P2 (維持率・導線)
- **字幕**: 現行 22字x2行・単語途中分割あり (QA P2-1)。実務基準は
  1行13〜16文字・毎秒4文字・文節改行。editor の分割ロジック改修が必要。
- **VOICEVOX 調声**: 速度のみ指定で抑揚パラメータ未調整。棒読みは
  離脱要因。抑揚 0.8〜1.2 の範囲でキャラ別に設定し、読点で間を作る。
- **中盤の山場**: points/quiz が後半固定で、本編 0:25〜5:30 が平坦に
  なりやすい。8〜11分ごとに山場を置く競合 (アニメ神話劇場) と違い、
  本編中にもキーワードカードや小クイズ的な「引き」を挟むべき。
- **終了画面・次回導線**: 次回予告はあるが、終了画面 (次の動画+登録)
  の最小構成と再生リスト設計が未整備。固定曜日・時刻とタイトルへの
  話数番号も未設定 (大手の共通インフラ)。
- **サムネイル**: 文字量が多め。実務知見は「12文字以下が強い」。
  キャラの視線は見出し側へ (向き合い原則をサムネにも適用)。

### P3 (品質・整合)
- **設定と素材の不一致**: スタイルガイドは「藍スーツ+山吹ネクタイ+
  教科書持ち」「白T+朱ベスト+リュック」だが、現素材はシャツのみで
  小物がない。どちらかに統一すること。
- **points/quiz でキャラが図版に被る** (QA P1-2)。セクション別に
  キャラ配置ルール (図版の外側 or 小型化) を editor に持たせるべき。
- 事実誤認 (弥生開始年代の旧説、「墾田永久私領の法」誤記) は
  qa-content が検出済み。教育系では信頼が登録者転換に直結するため、
  考証ゲートは公開前の必須工程として固定すること。

## 実施済み (本レビューと同時)
- バストアップ/全身スプライトの合成バグ修正 + 全話再生成
- 向き合い (先生反転) の全話適用 + スタイルガイド明文化

## 次のアクション候補 (優先順)
1. 冒頭構成の変更 (フック先行・OP短縮) — writer/editor
2. 表情差分 (各キャラ2〜3種) + 聞き手リアクション — artist/editor
3. 字幕分割の文節化と字数基準の変更 — editor
4. タイトル/サムネイルの型変更 (疑問形・数字・12文字) — writer/運営
5. 総集編と Shorts (一問一答) の企画追加 — 運営判断
6. 固定投稿スロット+話数番号+終了画面の整備 — 運営
