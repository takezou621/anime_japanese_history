## 所見リスト

### P1 (必須修正)

**[P1-1] キャラが全編「頭部のみ」で描画される — 全シーン (例: t=30 / 60 / 90 / 120 / 270 / 285 / 540s)**
- 現象: 両キャラとも胴体が一切見えず、地面・机レベルに巨大な頭だけが乗った状態。スタイルガイド規定の「立ち絵 900x1400 (ヒスト先生=藍スーツ+ネクタイ+教科書 / マナブ=白T+朱ベスト+リュック)」が画面上で確認できない。f04 (t=90) のように頭部が地面の後ろに半分埋まったように見えるフレーム、f02 (t=30) のように字幕帯の下に頭の下端が隠れるフレームもある。
- 原因特定 (参考): `assets/ep01/overlay/char_manabu.png` / `char_sensei.png` (900x1400) の実体が「下部55%のみに顔のアップ、上部は空、胴体なし・頭部下端がキャンバス下端で切断」という素材そのもの。合成位置 (pos=[330,420]/[1450,380]) より前に、アーティスト側の立ち絵生成が破綻している。
- 修正提案: (1) artist がフルボディ立ち絵を再生成 (全身+小物が1キャンバスに収まること)。(2) editor は pos を「頭頂部/センター基準」で見直し、足元が画面下端〜字幕帯の上に収まるよう配置。(3) 修正後は本QAで全シーン再検証。

**[P1-2] キャラ頭部が UI/コンテンツに重なる — points/quiz セクション (t≈450-540s, f16-f19)**
- 現象: points セクションで sensei の頭がタイムライン図版の中央 (縄文・弥生アイコン付近) に被る。quiz セクションでも頭がクイズボード右下に被る (f19 では両頭がボード両端から被る)。
- 修正提案: points/quiz ではキャラを図版の外側へ配置 (タイムラインの左右余白、ボードの外) するか、キャラを小型化して下段に寄せる。素材修正 (P1-1) 後に位置再調整。

### P2 (推奨)

**[P2-1] 字幕の改行が単語の途中で発生し、続け字が単独イベントで出る**
- 実測例 (ASS `video/ep01_FINAL_subs.ass` と一致):
  - t=0.00-4.75「…マナブと一緒にた」→ t=4.75-5.91「どっていきますよ。」(「たどって」分割)
  - t=57.86「…約1万年前から、縄文時」→「代が始まります。」(「縄文時代」分割)
  - t=66.74「…安定して暮らせるようになっ」→「たんです。」
  - t=270「…力の強い豪族も現れま」→「した。」
  - t=300「…金印をもらったことも書かれ」→「ています。」
  - t≈360 (f13)「えられています。」のみが単独表示
- 影響: テキストの欠損はないが、読み仮名の塊が分割され可読性・印象を損なう。2行22字以内ルールは守られているが、**分かち書き (文節単位) の考慮がない**。
- 修正提案: editor の字幕分割ロジックに文節単位の分割 (形態素ベース or 簡易辞書) を追加。分割が起きるときは話者ラベル付きの2イベントより、1イベント3行より、文節境界で折返す1イベント2行を優先。

**[P2-2] クイズボードの選択肢が最後まで表示されない (t≈470-540s, f17-f19)**
- 現象: quiz 3問すべてでボードの選択肢欄 (チェックボックス+空行) が空のまま。設問・選択肢は字幕のみで、ボードが「未完成の空フレーム」として長時間映る。
- 修正提案: editor がクイズ設問/選択肢をボード上に drawtext するか、writer の script.json に quiz 選択肢フィールドを追加して反映。空ボードのまま固定される現在の見せ方は学習効果を損なう。

### P3 (任意)

**[P3-1] 字幕帯 (半透明グレー帯) の有無がフレームによって不統一 (t=210s f08 は帯なし、f07/f09 は帯あり)**
- 帯なし時に米田の縞模様の上に白文字が乗り、可読性がやや低下する。帯の描画条件 (行数?) を統一することを推奨。

**[P3-2] マナブ頭部がフレーム左端でクリップされる (t=30s, f02)**
- 素材・配置修正 (P1-1) の際に、画面端からのセーフマージン (≥64px) を確保すること。

**[P3-3] オープニング t=0 でキャラ・タイトルが未出 (f01)**
- t=0 フレームでは登場モーション前で何もない黒板のみ。実害は小さいが、最初の0.5秒は完全な空席になる。最初の1秒にワイプ/フェードインを噛ませると safer。
