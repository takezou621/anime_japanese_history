# キャラクターアートの刷新決定 (2026-11-15, Muse)

## 問題 (実測)
現行 Open Peeps スプライトは実効3〜4色のベタ塗りで、肌色が #FFFDF7
(ほぼ紙白)、陰影・グラデーションなし。実測 (ep01 bust, 不透明画素):
- 先生: 紺シャツ 71% / 輪郭 16% / 肌(白) 5% が支配色
- マナブ: 赤シャツ 68% / 輪郭 14% / 肌(白) 11%
競合 (ずんだもん系・にっぽんぽん等) はフルカラーの陰影付きアニメ絵が
標準であり、この品質では勝負にならない。ユーザーの指摘で確定。

## 決定
- メインキャラ2名は Open Peeps を廃止し、フルカラーのアニメ調
  新スプライトに差し替える。デザインは Muse が生成・確定した。
- 原画は assets/characters_v2/source/ に格納 (デザインシート+全身)。
  - 先生: ダークブラウンの低めお団子+丸眼鏡、藍スーツ+白ブラウス+
    山吹色ネクタイ、歴史教科書持ち (スタイルガイド仕様に一致)
  - マナブ: 栗色の癖毛、白T+朱ベスト、紺ショーツ、リュック、そばかす
  - 両者とも自然な肌色、セル陰影+グラデーション、表情3種をシートで確定
- 生産スプライトは Muse が順次納品する: 全身 (切り抜き・900x1400
  透過PNG、同名 char_sensei.png / char_manabu.png)、バスト、表情差分
  (char_<name>_expr_<emotion>.png 形式)。

## DSH 側の作業
- タスク2 (表情差分) は peeps パーツ差し替え方式を中止し、新スプライトの
  表情ファイルを使う方式に変更する。
- editor は現行と同じファイル名・寸法・配置アンカーで新スプライトを
  受けられるようにし、納品され次第差し替えて再レンダーする。
- 品質ベンチマーク §3 (イラスト品質) の合格条件は新スプライト前提に更新:
  肌色が自然であること、陰影があること、表情3種以上、全話一貫性。

## 追補: アート制作の分担変更 (2026-11-15 ユーザー指示)
ユーザーの指示により、今後の絵のアート（キャラ・背景・プロップ・
サムネイル）はすべて Muse が作成し、プロジェクトへ納品する。
DSH プロジェクト内での絵の生成（artlib の絵画的出力）は行わない。
理由は品質差（実測と実見で確認済み）。
- 納品形式: 背景は 1920×1080 PNG を assets/epNN/scenes_v2/ に同名で納品。
  第1弾として ep01 の bg_school_lab / bg_jomon_village /
  bg_yayoi_rice_field / bg_kofun を納品済み。残りは話ごとに順次納品する。
- 例外: キーワードカード等の文字主体の UI は、日本語テキストの正確性が
  必要なため従来どおりコード生成を維持する（監査で合格判定済み）。
  パディング統一の修正のみ行う。
- DSH の役割: 納品アートの editor 統合、再レンダー、QC、運用まわり。
