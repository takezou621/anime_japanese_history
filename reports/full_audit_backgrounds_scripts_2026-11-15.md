# 全体監査: 背景・台本・その他要素 (2026-11-15, Muse)

ユーザーの指示「背景も台本もすべて見直す」を受けた監査結果。
キャラ刷新 (character_art_direction) と品質ベンチマークと合わせて正とする。

## 1. 背景 (artlib のコード描画)
実物確認: ep01 bg_jomon_village / bg_yayoi_rice_field ほか。
- 良い点: 時代考証が効いている (竪穴住居・環状集落・高床倉庫・水田・銅鐸)。
  構図がすっきりし、キャラと字幕の視認性を邪魔しない。全話で様式が統一。
- 問題: キャラと同じくフラットなベタ塗りで、空は単色、木と雲は
  スタンプの繰り返し、陰影・質感・空気感がない。「教科書の図解」の
  域を出ず、新しいフルカラーのキャラと並べると質感の落差が目立つ。
- 対応 (差し替えではなく artlib の格上げ):
  1. 空と地面にグラデーション、物体に落ち影、質感ノイズを追加する
     リッチ化パスを artlib に実装し全背景へ適用する。
  2. 木・雲のバリエーションを増やし、同一スタンプの反復感を消す。
  3. 前景要素 (手前の草・石・柵など) で奥行きを出す。
  4. 各話の冒頭シーン (フック部分) の背景だけは特に丁寧に作り込む。
  5. 色調は新キャラの彩度に合わせて微調整し、画面全体の統一感を取る。

## 2. 台本 (全10話を実測)
実測: 19〜20シーン/話、台詞86〜102本/話、クイズ3問/話 (構成は均一で良い)。
話者バランスは先生 約55% / マナブ 約45%。次回予告+登録CTA あり。
- 問題1 (文の長さ): 台詞の平均約30字、32字超が全体の約4割 (最大80字)。
  字幕作法 (13〜16字/行) と発話の自然さの両面で長すぎる。全話で
  意味の切れ目ごとに台詞を分割するリライトを行う。
- 問題2 (メタな受験フレーズ): 「そのまま受験で使えるフレーズですよ」
  のような制作側の言い回しが台詞に混ざり、物語への没入を壊す。
  受験ポイントの提示はキーワードカードと受験ポイントセクションに寄せ、
  会話内では自然な言い換えにする。
- 問題3 (掛け合いの単調さ): 「マナブの質問→先生の説明」の往復が支配的で、
  誤解・ツッコミ・逆質問・時代間の比較が少ない。独立したセカンドオピニオン
  (AMD Token Lab / MiniCPM) でも同じ指摘 (説明が断片的、反応が定型、
  因果の接続が弱い) を確認した。
  → 各話に最低限: マナブの誤解や勘違いを先生が正す場面、先生から
  マナブへの逆質問、前の時代との比較、を意図的に配置する。
- 問題4 (因果の接続): 事実の列挙になりがちな箇所は「なぜなら〜」の
  因果でつなぐ (ベンチマーク §2 の既定方針を台本リライトにも適用)。
- クイズ: 3択+解説の形式は良い。選択肢は時代的にあり得る誤答を中心にし、
  明らかに場外な選択肢だけにしない。

## 3. その他の要素 (棚卸し結果として DSH に確認を求めるもの)
- BGM・効果音: 選曲と音量バランスの現状を棚卸しし、ベンチマーク §4 の
  実測 (LUFS/ダッキング) と合わせて報告すること。
- プロップ (銅鐸・埴輪など): artlib のリッチ化パスに合わせて質感を揃える。
- サムネイル: 新キャラアートで全話作り直す (タスク5に含む)。
- タイトル/概要欄: タスク5の型変更に加え、概要欄に VOICEVOX クレジットが
  全話入っているか再確認する (craft 調査の必須事項)。

## 進め方
背景リッチ化と台本リライトは DSH の PR フローで実施し、Muse の監督
チェックがフレームと台本差分で検証する。台本リライトは考証ゲート
(タスク8) の対象とし、史実の変更が混ざらないよう差分を必ず確認する。
