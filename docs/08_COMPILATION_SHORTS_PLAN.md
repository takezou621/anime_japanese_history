# 総集編 & Shorts 制作計画 (タスク7 実制作版)

## 1. 総集編「日本史のすべて」 (1本, 60-70分)

### 構成
- 全10話 (ep01〜ep10) を時代順に連結
- 各話の冒頭に **時代タイトルカード** を3秒挿入 (第N話 + 時代名 + 年代範囲)
- 各話の OP (フック質問+タイトル表示) は総集編では短縮 (フック質問の最初の8秒のみ残す)
  → テンポよく全体を通し視聴できる構成
- ending (次回予告+登録導線) は総集編ではカットし、最後にまとめ ED を1回だけ挿入

### 技術方式 (tools/editor/compile_compilation.py)
1. 全10話の FINAL.mp4 から各話セグメントを切り出し
   - ffmpeg stream copy は不可 (カット点がキーフレームと合わないため) →
     一度全部 decode→encode する案より、**各話を中間ファイル (同一エンコードパラメータ) に
     事前カット** して concat demuxer で連結する方式
2. タイトルカード: artlib で生成 (bg_timeline 風のデザイン+「第N話 {時代名}」) →
   3秒の MP4 にエンコード (他話と同一パラメータ)
3. concat demuxer (-c copy) で連結 → 最後にまとめ ED (登録導線+シリーズ再生リスト案内) を挿入
4. QC: duration = Σ各話 + タイトルカード, ラウドネス全話均一, 黒フレーム検出
5. 出力: video/compilation_FINAL.mp4 + video/compilation_QC.json

### 所要見積
- 中間ファイル生成: 10話 × 約5分 = 50分
- 連結+QC: 約5分 → 合計約1時間 (agent 1回のセッションで完結)

## 2. Shorts「一問一答クイズ」 (最低3本, 各18秒・縦型1080x1920)

### 切り出し元
- 優先: ep01 (縄文・弥生), ep04 (鎌倉), ep08 (幕末) — 頻出度上位の3時代
- 各話 quiz セクションの 3問から1問を選択 (正答+解説が自完結しているもの)

### フォーマット (tools/editor/make_shorts.py)
1. quiz シーンを抽出 (timing.json の quiz セクション開始から問題ビート区間)
2. 縦型リフレーム: 1080x1920 にセンタークロップ (キャラと黒板中央を保持)
3. テロップ: 「問題」(3秒) → 「ア/イ/ウ 選択肢」(5秒) → 「正解は…」(3秒) → 「解説」(5秒)
   → script.json の quiz 配列から自動生成 (テロップは ass で焼き込み)
4. 冒頭0.5秒にフックテキスト「この問題、解けますか?」
5. 音声は元の narration WAV 区間をそのまま使用 (timing.json で正確に切り出し)

### 品質基準
- 1080x1920 / 30fps / -14 LUFS / 18-22秒 / 文字切れゼロ
- 出力: video/shorts_epNN_q01.mp4 形式 + QC json

### 制作順
1. ep01 q01 (磨製石器) → テンプレ確定
2. ep04 q01 (壇ノ浦) / ep08 q01 (征夷大将軍) → 計3本
3. 残り27問は需要を見て追加 (テンプレがあれば量産可能)
