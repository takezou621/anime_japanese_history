# スタイルガイド — アート & サウンド

## 1. アートディレクション

「アニメ神話劇場」風の**アニメ調フラットアート** + モーショングラフィックス。
難しくなりがちな受験内容を、明るくポップに見せる。

### カラーパレット

| 用途 | 色 |
|---|---|
| メイン (信頼の藍) | `#2b4a8b` |
| アクセント (夕日の朱) | `#e8543f` |
| ハイライト (山吹) | `#f5b942` |
| サブ (若草) | `#5aa469` |
| 空グラデ | `#8ec9e8 → #dff1f7` |
| 地面/土 | `#c9a36b` / `#8a6f4d` |
| テキスト基本 | `#26282e` |
| 白 UI | `#fffdf7` (少し温かい白) |

### シーン絵のルール
- 1920×1080。空・地面・建造物・人物・小物をフラットなシェイプで構成し、
  影は同系色の濃いフラット1色 (グラデ乱用禁止)
- 人物はアニメ調簡略化: 大きな目・シンプルな輪郭線 (2–3px 同系暗色)
- 時代感覚: 縄文=土器・竪穴住居, 弥生=水田・高床倉庫・銅鐸, 古墳=前方後円墳・埴輪
- 各シーンに「時間の空気」: 明朝/夕方/夜は空色を変える

### キャラ立ち絵 (透過PNG, 約 900×1400)
- ヒスト先生: 藍色スーツ + 山吹のネクタイ、眼鏡、教科書持ち。優等生スタイル
- マナブ: 白T + 朱色ベスト、リュック。元気系少年
- 目は大きく、頬に丸い赤み。髪はシンプルな房分割でアニメ感

### キャラの向き (向き合い原則 — 2026-11-15 追加)
- 対話シーンでは2人は**向き合う**こと。同方向を向いた2ショットは禁止。
  左配置のキャラは右向き、右配置のキャラは左向き (視線が画面中央で交わる)。
- 配置は全話で固定 (script.json 実測: マナブ=左 170回、先生=右 190回)。
  素材の顔は右向きのため、先生は左右反転して使う
  (tools/peeps/compose_peeps.py の CHARACTERS["char_sensei"]["flip"]=True
  で生成時に反転。全話の全身・バスト両素材に適用済み)。
- サムネイルでも同じ原則: キャラの視線は見出しテキスト側 (画面内側) へ向ける。

### overlay_text スタイル定義 (editor 実装の drawtext/ASS と artlib のバッジで共用)

| style | 見た目 |
|---|---|
| `title_main` | 72px NotoBlack, 白文字 + 朱フチ, 中央上1/3, fade_up |
| `era_badge` | 角丸カプセル (藍地に白 44px), 左上, slide_in_left |
| `keyword_card` | 白角丸カード + 藍枠, 大きめキーワード 64px, pop_in |
| `exam_banner` | 朱バナー「ここが受験ポイント!」白 56px, slide_up |
| `year_number` | 年号強調 96px 山吹, zoom_in |
| `subtitle` | 42px 白文字 + 黒フチ3px, 下部 92%, 話者名ラベル付き |

### モーション原則
- 静止 3 秒以上禁止。全背景に kenburns (ゆっくり zoom 1.0→1.06 など)
- 登場モーションは 0.4–0.6s, ease-out (pop_in は overshoot 5%)
- セクション遷移は 0.5s クロスフェード or ワイプ (朱色の斜めワイプ)

## 2. サウンドディレクション

### ナレーション (VOICEVOX)
- ヒスト先生: 四国めたん/ノーマル, speed 1.05 — 落ち着いた解説
- マナブ: ずんだもん/ノーマル, speed 1.08 — 元気な疑問・相槌
- 対話テンポ: ビート間 0.6s。先生の解説は 2〜3 文で区切る (字幕可読性)
- 「だ・である」ナレーション × キャラは「のだ!」「〜だよ」口調

### BGM (numpy 合成, 著作権完全クリア)
- opening: 明るいメジャー (C major, 120bpm, パッド+アルペジオ)
- story: 落ち着いた (A minor→F, 90bpm, パッド中心)
- points: 軽快 (F major, 110bpm, スタッカート)
- quiz: タメる (Dm, 100bpm, ドラム強め)
- ending: 温かい (G major, 85bpm)
- ループ长: 16〜32 小节生成し、シーン長にループ/フェード
- ミックス: ナレ時 -18dB, 無音区間では -8dB まで持ち上げる (ducking は簡易エンベロープ)

### 音量
- マスター: -14 LUFS (YouTube 基準), TP -1.5 dB
- ナレーション VOICEVOX volumeScale 1.2 生成 → mix で頭出し確認

## 3. 字幕ルール
- 1 行 ≈ 22 文字以内、最大 2 行
- 話者名ラベル: 「ヒスト先生:」を色付きで先頭に (先生=水色, マナブ=緑)
- 専門用語初出は keyword_card と連動させる

## 4. サムネイル (1280×720)
- 左 2/3: エピソード主ビジュアル + 大きな時代名 (96px 白 + 朱フチ)
- 右 1/3: キャラ + 「受験」バッジ
- 常にコントラスト強・文字の読みやすさ最優先 (縮小表示で判読できること)
