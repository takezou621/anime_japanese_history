# 企画書 — アニメ日本史ラボ

> 中学・高校受験対策 × アニメ× AI完全自動制作

## 1. コンセプト

**「アニメ日本史ラボ」** — ベンチマーク「アニメ神話劇場」(https://www.youtube.com/watch?v=RcKP0dwKPFM) のような
アニメストーリーテリングの楽しさに、**受験で得点になる知識整理**を融合させる。

- 視聴層: 中学受験・高校受験の受験生 (とその保護者)
- 1本 5〜10 分 / 1080p 30fps / 日本語字幕焼き込み
- AI (エージェントチーム) が脚本〜レンダリングまで完全自動で制作。人間は関与しない。

## 6. 品質基準 (Quality Bar)

1. **映像**: 1920×1080 / 30fps / H.264 (CRF 18) / 静止画にモーション (Ken Burns・パン・ズーム・クロスフェード) を必ず付ける。静止画のまま3秒以上置かない。
2. **音声**: ナレーションは必ずレンダリング前に全セグメント生成し、タイミングは実音声長から逆算。ラウドネスは YouTube 基準 -14 LUFS に正規化。
3. **BGM**: 著作権フリー (自前合成)。ナレーションより -18 dB 低くミックス。
4. **字幕**: 全ナレーション・対話を焼き込み字幕にする (アクセシビリティ)。
5. **教育性**: 各話に受験ポイント3点以上 + クイズ3問を含む。
6. **検品**: レンダリング後に自動 QC (長さ・音声レベル・黒フレーム検出) を実行。

## 7. 運営 (YouTube)

- メタデータ (タイトル/概要/タグ/チャプター) は YAML で自動生成
- サムネイル 1280×720 を自動生成 (テンプレ + 各話ビジュアル)
- アップロードは YouTube Data API v3 用スクリプトを整備
  (認証情報がない環境では dry-run: メタデータと動画を成果物として出力)
